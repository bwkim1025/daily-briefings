# 부동산·이사 / 육아·교육 — 매일 아침 작성 규칙 (루틴 4에 넣을 초안)

2026-11-19 추가. 기존 6종(파이낸셜·국제·건강·스포츠·테크·날씨)과 같은 방식으로 쓴다. 이 문서는 루틴 4 '데일리 브리핑 6종 게시'에 붙일 규칙 초안이며, 루틴 문구 수정은 병우님 쪽(브리핑 봇)에서 한다.

## 공통

- 파일: `realestate/briefings/YYYY-MM-DD.md`, `parenting/briefings/YYYY-MM-DD.md` (KST 날짜). 커밋 뒤 `node scripts/update-briefing-index.cjs` 로 색인을 갱신하고 함께 커밋한다(기존 6종과 같음).
- 순서: 기존 6종을 다 올린 뒤 부동산 → 육아 순서로 한 편씩 조사·작성·커밋·읽기 확인한다. 한 편이 실패해도 다른 편은 보존한다.
- 형식: 기존과 같은 `# YYYY-MM-DD` → `> 정보 기준 …` 한 문단 → `## TODAYS_STORY` → 분야 섹션들 → `## ONE_LINER` → `## AUTHOR`. 각 항목은 `### 제목 — 부제`, 본문 한 문단, `#### Why it matters`(필요할 때), `#### Takeaway`(TODAYS_STORY만, 해석은 '(해석)' 표시), `#### Source`(날짜와 URL).
- 한국어만. 수치·URL·인용·날짜를 지어내지 않는다. 실제로 연 원문만 적고, 열지 못했거나 아직 발표 전이면 '확인불가'로 쓴다.
- 반복 금지: 어제·최근 호를 전문으로 읽고, 새 진전이 없는 같은 소식은 다시 쓰지 않는다. 새 소식이 없으면 섹션을 비우지 말고 '오늘 새 소식 없음(확인 범위: …)'으로 짧게 적는다.
- 공개 저장소다. 가족 이름, 아이 나이·생일, 계약·대출·소득·보유 자산 같은 가족 정보는 쓰지 않는다. '초등 입학을 앞둔 가정', '2029년 입주 예정 단지'처럼 일반화한다. 모유 수유 여부 같은 가족 상황은 묻거나 조건을 달지 않는다.
- 투자·청약·대출 권유를 하지 않는다. 사실과 해석을 구분한다.
- 앱 팟캐스트: 분야 클립을 만들 때 대본 머리는 `앱 부동산 첫 번째 항목입니다.` / `앱 육아 첫 번째 항목입니다.` 를 쓰고, 항목 JSON의 `n`은 `부동산 1`, `육아 1`, `cat`은 `realestate`, `parenting` 으로 한다(`/workspace/podcast/README.md` 3-2단계).
